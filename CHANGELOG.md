# Changelog

## 0.0.1

Initial release.

- Add Book — imports a Blogger blog's posts as local `.html` files, tracked in a `blog.yaml` manifest.
- Sync Changes — three-way sync between local files and Blogger, with conflict resolution.
- Consolidate Posts — re-dates posts published under different months and rewrites cross-chapter links.
- Preview — builds and serves a locally-rendered copy of the book via Live Server.
- Google sign-in — installed-app OAuth2 flow for Blogger API access.
